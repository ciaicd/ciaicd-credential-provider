# Code of conduct

Be respectful, constructive and considerate. Discuss technical decisions using
facts and reproducible examples. Welcome contributors with different backgrounds
and experience levels.

Harassment, discrimination, threats, personal attacks, doxxing and sharing private
information or credentials without consent are not acceptable in issues, pull
requests, reviews or other project spaces.

Maintainers may edit or remove inappropriate content, close discussions, or limit
participation to protect contributors. Report concerns privately to a repository
maintainer through GitHub. Security vulnerabilities follow `SECURITY.md`.
